# Parked advanced helpers

These channel and local-codebase Knowledge Base helpers are preserved for
future review, but they are deliberately outside the installable `sharenow/`
skill directory. The public package stays focused on explicit Site publishing,
private Drive operations, and browser-mediated account access.

They remain covered by the shell regression suite so later work can restore a
capability without reconstructing it. Do not add these files to an installable
skill until their remote-content and local-directory upload boundaries have a
separate security review.
